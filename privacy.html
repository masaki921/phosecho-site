プライバシーポリシー

最終更新日：2026年10月12日 ／ 運営者：PhosEcho（個人事業、沖縄県那覇市）／ 連絡先：masaki@phosecho.com

PhosEcho（以下「当方」）は、ウェブサイト phosecho.com、Steam ストアページの日本語ローカライズ事業、および教養系動画メディア「PhosEcho Media」（YouTube チャンネル）の運営にあたり、以下のとおり個人情報を取り扱います。

1. 取得する情報

  • お問い合わせ・ご注文時：お名前、メールアドレス、ご依頼内容。決済は Stripe, Inc. が処理し、当方はカード番号を保持しません。
  • ウェブサイトの閲覧時：当サイトは GitHub Pages で配信されており、配信事業者がアクセスログ（IP アドレス等）を取得する場合があります。当方独自のアクセス解析や広告用 Cookie は使用していません。
  • YouTube チャンネル：視聴者の個人情報を当方が直接取得することはありません。視聴データは YouTube（Google）のプライバシーポリシーに従って取り扱われます。

2. 利用目的

  • ご依頼への対応、納品、請求および連絡
  • サービスの改善、および法令に基づく対応

3. 第三者提供

法令に基づく場合を除き、本人の同意なく第三者に個人情報を提供しません。業務上必要な範囲で、決済（Stripe）、メール送受信（Google Workspace）、ホスティング（GitHub）の各事業者に処理を委託しています。

4. YouTube API サービスの利用について

当方は、PhosEcho Media の動画を自身の YouTube チャンネルへ投稿・管理するために、YouTube API サービスを利用する非公開のソフトウェア（API クライアント名：PhosEcho Media Uploader）を運用しています。このソフトウェアは一般に公開しておらず、当方自身のみが使用します。

  • 当方の API クライアントは YouTube API サービスを利用しており、利用者は YouTube 利用規約 および Google プライバシーポリシー に拘束されます。
  • 取得・利用するデータは、当方自身の YouTube チャンネルに関する情報（動画のアップロード、タイトル・説明・公開日時の設定、自身のチャンネルの分析データの読み取り）に限られます。
  • 第三者（視聴者や他のユーザー）の個人情報や認証情報を取得・保存・共有することはありません。
  • 当方が保存する認証情報（OAuth トークン）は当方の端末内にのみ保管し、第三者に共有しません。アップロードした動画の記録（動画 ID・URL・公開日時）は当方の管理用に保存します。
  • YouTube のコンテンツやデータを、YouTube のプラットフォーム外で保存・再配布・販売することはありません。
  • 利用者（当方自身）は、Google アカウントのセキュリティ設定ページから、いつでも当方の API クライアントによるデータへのアクセス権を取り消すことができます。

5. データの保存期間と削除

お問い合わせ・ご注文に関する情報は、対応完了後、法令上必要な期間（税務上の保存義務など）を経過した後に削除します。YouTube API 経由で取得した自身のチャンネルの分析データは、集計目的で保存し、不要になった時点で削除します。個人情報の開示・訂正・削除のご希望は、下記の連絡先までご連絡ください。合理的な期間内に対応します。

6. 安全管理

個人情報および認証情報は、アクセス制限された端末・アカウントで管理し、漏えい・滅失・毀損の防止に努めます。

7. 改定

本ポリシーは必要に応じて改定し、改定後の内容は本ページに掲載した時点で効力を生じます。
